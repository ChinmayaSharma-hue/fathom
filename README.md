# Fathom

A daily rare-answer trivia game: 7 prompts a day, 25 seconds each. The rarer your (valid) answer,
the deeper your bathysphere sinks. This is the static edition: scoring runs in the browser with
model-estimated rarity, and nothing is recorded.

Built from a Wikidata pipeline; source and the full version with a recording backend live in a
separate repository.
